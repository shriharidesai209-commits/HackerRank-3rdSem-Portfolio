\# Sparse Arrays



\## Problem Description



Given a collection of strings and a set of query strings, determine how many times each query string occurs in the original collection.



\## Approach



\- Store the frequency of each string using a hash map.

\- Traverse the input strings and increment the frequency of each string.

\- For every query, look up its frequency in the hash map.

\- Return the frequency for each query.



\## Complexity Analysis



\- \*\*Time Complexity:\*\* O(N + Q)

\- \*\*Space Complexity:\*\* O(N)
