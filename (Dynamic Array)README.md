\# Dynamic Array



\## Problem Description



Given a sequence of queries, perform operations on dynamic sequences and maintain the required `lastAnswer` value using the query index and bitwise XOR operation.



\## Approach



\- Create a collection of dynamic sequences.

\- For each query, calculate the sequence index using the XOR operation with `lastAnswer`.

\- Perform the required operation based on the query type.

\- Update `lastAnswer` when required.

\- Store the answers generated by type-2 queries.



\## Complexity Analysis



\- \*\*Time Complexity:\*\* O(N + Q)

\- \*\*Space Complexity:\*\* O(N)
