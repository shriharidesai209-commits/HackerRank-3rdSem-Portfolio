\# Compare the Triplets



\## Problem Description



Given two triplets representing the scores of Alice and Bob, compare the corresponding elements and calculate their respective scores.



\## Approach



\- Compare the first elements of Alice's and Bob's triplets.

\- Compare the second elements.

\- Compare the third elements.

\- If Alice's value is greater, increment Alice's score.

\- If Bob's value is greater, increment Bob's score.

\- If both values are equal, neither score is incremented.

\- Return the two scores.



\## Complexity Analysis



\- \*\*Time Complexity:\*\* O(1)

\- \*\*Space Complexity:\*\* O(1)
